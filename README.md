# Quiz-O-senhor-dos-aneis.c

Este repositório é referente a um projeto universitário da disciplina de Algoritmos e Pensamento Computacional.

O intuito deste código é exclusivamente educacional, tendo como objetivo a prática de conceitos básicos de programação em C, como estruturas de repetição, estruturas condicionais, entrada e saída de dados e validação de informações.

Por se tratar de um projeto acadêmico, não há finalidade comercial e não são utilizadas técnicas avançadas de otimização ou heurísticas. O foco está no aprendizado e na aplicação dos conceitos apresentados durante a disciplina.
